## 3. Candidate Readiness Checklist

Before sitting for the Google Cloud Professional Data Engineer exam, verify your ability to answer the following without consulting reference documentation:

- [ ] Can you diagram how a streaming message flows from an IoT publisher through Cloud Pub/Sub, into an Apache Beam pipeline on Dataflow, and into BigQuery using the Storage Write API, explaining exactly where data loss or duplication could occur and how each service prevents it?
- [ ] Can you design a Bigtable row key for time-series sensor data that avoids hotspotting while supporting sub-10ms scans for the most recent events?
- [ ] Do you know when to use BigQuery partitioning vs. clustering, how cluster column ordering affects queries, and how to verify partition pruning in the `INFORMATION_SCHEMA`?
- [ ] Can you compare Cloud Spanner vs. Cloud SQL vs. AlloyDB across availability SLAs (99.95% vs 99.99% vs 99.999%), replication consistency (Paxos vs asynchronous), and failover times (RTO/RPO)?
- [ ] Do you understand VPC Service Controls, Private Service Connect, and why standard VPC firewall rules cannot protect multitenant Google Cloud APIs like BigQuery?
- [ ] Can you configure an Apache Airflow DAG to be fully idempotent during historical backfills using atomic MERGE statements or partition replacements?
- [ ] Can you explain the difference between BigQuery on-demand pricing, baseline reservation slots, and autoscaling slots under Enterprise Edition?
- [ ] Can you calculate network transfer times for large-scale data migrations, select between STS, DMS, and Transfer Appliance, and design post-migration validation checks?
